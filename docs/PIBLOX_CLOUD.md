# PIblox Cloud

## Current stage: isolated local streaming prototypes

The prototypes live in services/piblox-cloud:

- **MJPEG demo (127.0.0.1:8787):** original Pillow-rendered test arena, browser video, and directional input over WebSocket.
- **WebRTC demo (127.0.0.1:8790):** browser-side offer/answer negotiation and an animated synthetic video track generated by the server.

The WebRTC page reports connection state, FPS, and decoded frame count. It uses a separate page and port, leaving the MJPEG demo intact.

## Security boundary

Both prototypes are local-only:
- Services bind to loopback addresses.
- The WebRTC HTTP routes reject non-loopback clients and limit peer sessions.
- Neither prototype captures the desktop, launches third-party games, or accepts executable paths from clients.
- The WebRTC demo sends synthetic video only and has no remote input channel.
- Sessions are held in memory and are not production-grade user sessions.

Do not deploy these prototypes as public endpoints. Remote hosting needs authenticated session provisioning, TLS, authorization, rate limits, process isolation, resource quotas, abuse prevention, and a reviewed threat model.

## Verification status

The WebRTC branch includes unit tests for its API routes, browser page, SDP validation, and loopback restriction, plus a GitHub Actions workflow. Those automated tests do not prove successful media playback in every browser or device; an actual browser run is still required.

## Planned stages

1. **Local WebRTC validation:** verify browser media playback and measure frame/connection behavior.
2. **Secure session service:** design short-lived credentials, authenticated ownership, and expiry.
3. **Worker isolation:** disposable workers for applications explicitly permitted in the remote environment.
4. **Desktop client:** integrate the protocol into PIblox after server behavior is stable.
5. **Performance:** measure input latency, frame latency, bitrate, packet loss, and CPU/GPU utilization.

No production release, public cloud hosting, or third-party game compatibility is claimed at this stage.
