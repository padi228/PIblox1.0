# Security policy

PIblox is an early preview. Use it only from source or releases published from this repository.

## Never collect or commit
- Roblox passwords, session cookies, browser profiles, or authentication tokens.
- GitHub access tokens, API keys, passwords, private service credentials, or personal data.
- Files from Roblox installation folders unless a feature explicitly documents why and asks the user first.

## Link handling
- The game-link field accepts only HTTPS roblox.com links, numeric experience IDs, or search text.
- Search text is sent to the official Roblox website by opening the browser.
- Do not add code that bypasses Roblox security, anti-cheat, access controls, or regional restrictions.

## Reports
Diagnostics may include local OS details and Roblox installation paths. Review a report before sharing it publicly.

## Reporting
Do not publish secrets or sensitive account details in GitHub issues. For a security concern, contact the repository owner privately using GitHub's supported contact options.
